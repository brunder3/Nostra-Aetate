## Los Aetate – Open World im Browser

Eine komplette Stadt mit 100 Häuserblocks, fließendem Verkehr mit Ampeln, Passanten, Polizei mit fünf Fahndungsstufen, Tag-/Nachtzyklus, Regen, Missionen und Fahrzeugen zum Klauen. Alles in einer einzigen HTML-Datei; Three.js wird von einem CDN geladen.

**Steuerung**

| Aktion | Taste |
|---|---|
| Laufen / Rennen / Springen | W A S D / Shift / Leertaste |
| Umsehen | Maus |
| Fahrzeug ein-/aussteigen | F |
| Gas / Bremse / Handbremse / Hupe | W / S / Leertaste / H |
| Waffe wechseln / Schießen | 1, 2 / Linke Maustaste |
| Kamera wechseln | C |
| Zeit vorspulen | T |
| Ton an/aus | M |
| Pause (Grafik, Regen, Tageszeit) | Esc |

**Missionen**

- Gelber Marker: Kurierauftrag (Paket abholen, gegen die Zeit abliefern)
- Blauer Marker: Fahrzeug-Export (Auto in der Garage abliefern, Preis nach Modell und Zustand)
- Rotes Kreuz: Krankenhaus (Heilung für $100)
- Grüne Scheine: Bargeld

Hinweis: Am flüssigsten läuft das Spiel in einem Desktop-Browser mit aktivierter Hardwarebeschleunigung. Die Grafikqualität lässt sich im Startbildschirm und im Pausenmenü umstellen.
